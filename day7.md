💡 Key Learnings from Day 7
Not all tasks need the same model — matching model to task = efficiency
Effort level matters — Standard is the sweet spot for most daily work
Claude works best with context — role + goal + format = 10x better output
Haiku is underrated for speed tasks; Opus is overused by beginners
A personal workflow strategy makes AI usage intentional, not random
