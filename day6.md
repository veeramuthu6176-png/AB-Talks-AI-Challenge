# Day 6 – ATS Resume Optimization with Claude AI

## Original Resume
- File: Veeramuthu_Resume-2.docx
- ATS Score: 52/100
- Issues: Emoji in contact line, outdated "Career Objective" section,
  missing CGPA, weak bullet points, incomplete skills/certifications

## Optimized Resume
- File: Veeramuthu_ATS_Resume.pdf
- ATS Score: 86/100
- Format: Single-column, A4, ATS-clean (no tables/icons/columns)

## Key Changes Made
1. Removed emoji (📧 📞) from contact — ATS parsers corrupt them
2. Renamed "Career Objective" → "Professional Summary"
3. Added CGPA: 8.5 / 10.0 under Education
4. Expanded Skills with LLMs, NLP, TensorFlow, Keras, HuggingFace
5. Strengthened bullets with action verbs (Designed, Implemented, Developed)
6. Added missing project: Backpropagation Neural Network (XOR)
7. Added Certifications: Google Cloud GenAI, IICT AI Skills House, ABTalks

## Key Learnings
- ATS systems parse plain text — emoji and columns break parsing
- "Professional Summary" outperforms "Career Objective" in modern ATS
- Every real project and certification belongs on the resume
- Strong action verbs improve recruiter readability score
- CGPA above 7.5 should always be visible to recruiters
