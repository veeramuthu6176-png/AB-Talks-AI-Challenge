# Day 2 - Prompt Engineering Challenge

## What I Learned
- Lazy prompt vs Engineered prompt difference
- Clarity, Context, Constraints matter in prompting
- Better prompts = Better AI output

## Lazy Prompt
"Create an image explaining Prompt Engineering"

## Engineered Prompt
You are a visual educator. Create a detailed explanation 
of Prompt Engineering as an infographic.
Include: definition, 3 core principles, before/after 
example, use cases. Target: beginner AI learners.

## Key Takeaway
Engineered prompts give structured, high-quality output 
compared to vague lazy prompts.
