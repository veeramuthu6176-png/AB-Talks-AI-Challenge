# Day 8 - Personal Environmental Health Analyzer

## Project Overview
Built an interactive Environmental Health Analyzer dashboard using HTML, CSS and JavaScript.

## Features
- Average AQI calculation
- Highest AQI city identification
- Lowest AQI city identification
- City selection dropdown
- AQI comparison chart
- PM2.5 comparison chart
- Environmental risk analysis

- JavaScript

- GitHub project management
